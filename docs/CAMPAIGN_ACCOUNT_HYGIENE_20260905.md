Scope rule: **only** accounts created by this verification campaign are listed.
No legitimate user or admin account is touched.

## Mechanism status

- The application has **no admin user-disable/delete route** (verified by route
  inspection of all controllers) and this execution environment has **no
  production database credentials** (credential policy: only environment-provided
  secure credentials are used; none exist for the Neon DB).
- Therefore campaign accounts cannot be deleted from this environment. They are
  listed below with the exact, scoped removal statement for the owner/DBA to run
  **after** the final deployment, plus the risk assessment that makes deferral
  acceptable.

## Risk assessment (why deferral is safe)

- Every listed account has role `CONSUMER` (server-enforced; client role
  injection is rejected — verified live).
- All have zero commerce state (no orders, no wardrobe items — verified via the
  per-user ownership counts before removal of the diagnostic endpoint).
- They cannot reach admin/brand routes (RBAC verified live: 403).
- They hold no generated-image data (VTON results are never persisted).
