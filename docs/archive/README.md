# Historical Reports Archive

Root-level campaign reports from earlier development rounds (V3–V6 forensic
reports, completion/remediation matrices, early hosting guides). They are
kept for provenance only — **the canonical, current documents live in
`docs/`** (e.g. `FINAL_CLOSURE_REPORT_20260905.md`,
`PRODUCTION_DEPLOYMENT_CONTRACT.md`, `AUDIT_REMEDIATION_2026-09-06.md`).

Nothing in the build references these files; `PRODUCTION_KEYS_AND_ENV_CONFIG.md`
and `DEPLOYMENT_GUIDE_FREE_HOSTING.md` are named as historical provenance in a
comment in `backend/app/core/config.py` and are superseded by
`docs/PRODUCTION_DEPLOYMENT_CONTRACT.md`.
